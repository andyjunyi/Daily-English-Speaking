# Daily English Speaking

日常生活英文口說練習方案 — 適合台灣國高中生的日常英語會話教材。

## 資料夾說明

| Folder | Purpose |
|--------|---------|
| `topics/` | 11 個主題分類（每個主題獨立 .md 檔） |
| `dialogues/` | 對話腳本、角色扮演、翻牌學習網頁 |
| `vocabulary/` | 完整 JSON 詞庫（58 句） |
| `exercises/` | 練習題 CSV（填空、配對、造句） |
| `scripts/` | 自學計畫（14 天進度表 + 學習方法） |
| `audio/` | 錄音檔、發音練習音檔 |
| `reference/` | 參考資料、文法重點、文化筆記 |

## 內容現況

- **總句數：** 58 句地道口語短句
- **主題數：** 11 個（算了、辛苦了、扎心、社交語氣、別自以為是、誰怕誰、何必呢、我來、當我沒說、巧合、單句精選）
- **難度分級：** 入門 30 句 · 中級 20 句 · 進階 8 句
- **最後更新：** 2026-05-23
- **來源：** 地道英文口語短句

## 使用方式

### 學生自學（每天 10–15 分鐘）

1. **翻牌記憶** — 開啟 `dialogues/flashcards.html`，點擊卡片練習英翻中
2. **跟讀模仿** — 每句唸 3 次，注意語氣
3. **情境造句** — 用當天句子造一個自己的句子
4. **角色扮演** — 參考 `dialogues/roleplay-scenarios.md` 和同學對練
5. **每天進度** — 跟隨 `scripts/self-study-plan.md` 的 14 天計畫

### 教師使用

1. 課前暖身：用 flashcards.html 投影練習翻牌
2. 課堂活動：角色扮演腳本分組練習
3. 回家作業：填空練習 + 自製對話

## GitHub Pages 互動學習

開啟 `dialogues/flashcards.html` 即可使用翻牌學習頁面：
- 搜尋關鍵字（英文或中文）
- 按難度篩選（入門 / 中級 / 進階）
- 按情境標籤篩選
- 點擊卡片翻面看中文翻譯
